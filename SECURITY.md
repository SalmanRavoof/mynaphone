# Security policy

Report a vulnerability through [GitHub's private vulnerability reporting](https://github.com/SalmanRavoof/mynaphone/security/advisories/new)
on this repository, or
contact the maintainer through [salmanravoof.com](https://salmanravoof.com). Please don't open a public issue for it. You
will hear back within a week.

What the app can reach and what it sends is described in [Security and privacy](docs/security.md).
