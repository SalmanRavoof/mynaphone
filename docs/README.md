## Words used across these pages

| Word | Meaning |
|---|---|
| Take | One attempt to record one song, from its first second to its last |
| Kept, discarded, skipped | A take that passed every check; a take that failed one and was set aside with the reason; a song that wasn't recorded at all, for example because it's already in the library |
| Inbox | The folder of verified takes waiting to be identified and filed |
| Library | Your finished collection, sorted into `Soundtracks`, `Artists` and `Unsorted` |
| Tier | The quality a service played a song at, such as Spotify Free, Premium or lossless |
| Bridge | One of the 2 optional extensions, for Spotify and for the browser, that tell Mynaphone more than Windows does |
| Harvest mode | Skipping songs already in the library, so an unattended playlist records only new ones |
| Fingerprint | A compact description of how a recording sounds, used to look it up |
