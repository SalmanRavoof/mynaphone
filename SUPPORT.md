# Getting help

Mynaphone has one maintainer and no support staff, so the documentation is the fastest place to look.

1. Run **Setup check** > **Run checks** in the app and fix anything marked Problem.
2. Find your symptom in the [troubleshooting guide](docs/troubleshooting.md). A discarded take's
   reason is explained in [every discard reason](docs/troubleshooting.md#every-discard-reason).
3. Check the [questions and answers](docs/faq.md) for quality, accounts, devices and privacy.
4. Search the [existing issues](https://github.com/SalmanRavoof/mynaphone/issues?q=is%3Aissue), open
   and closed.

If none of that helps, [open an issue](https://github.com/SalmanRavoof/mynaphone/issues/new/choose).
The bug report form asks for your Windows version, the Mynaphone version and the relevant log lines,
which [where the logs are](docs/troubleshooting.md#where-the-logs-are) shows you how to find.

Report a security problem privately instead, as the [security policy](SECURITY.md) describes.
